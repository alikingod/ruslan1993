# Проверка готовности

Проверено при реализации:

- TypeScript: `npm run typecheck` без ошибок.
- Production: `npm run build`, готовые статические файлы в `dist/`.
- `npm test`: возраст до/в/после дня рождения, будущие годы, достижимая победа на всех трёх сложностях, границы шкал, последствия игровой аварии, условия финала.
- Chromium: открытие всех маршрутов, отсутствие ошибок JavaScript, отсутствие горизонтального переполнения на ширине 390 px.
- Полный сценарий: пропуск загрузки → вход → победа на сложности «Легенда» → академия 5/5 → пять вызовов → ярость → восстановление → открытый финал.
- Все 10 достижений получены действиями через интерфейс, включая секреты и поздравление. Перезагрузка сохраняет прогресс. Подтверждённый сброс очищает его.
- Подстановка локальной даты 28.12.2026: праздничное окно появляется автоматически, интерфейс получает золотой режим, возраст — 33 года.
- Визуальная проверка центра управления при ширинах 1440 и 390 px.

Настоящее устройство iPhone и Safari в этой среде недоступны. Для совместимости используются HashRouter, системные шрифты, safe-area, viewport-fit, WebKit AudioContext fallback, адаптивные кнопки и reduced-motion. Окончательную проверку на своём iPhone можно выполнить по опубликованной ссылке.

GitHub Pages публикует workflow `.github/workflows/pages.yml` из `main`. Выбор GitHub Actions как источника Pages выполняется в настройках репозитория; инструкция в README.
