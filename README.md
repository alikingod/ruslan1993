# РУСЯ 1993 — ЛЕГЕНДА СГУЩЕНИЯ

Персональный подарок Руслану, наставнику и аппаратчику сгустителей. Восемь страниц, игровой симулятор, академия, секреты, десять достижений и праздничный режим. Дружеская пародия, неофициальный проект. Все показатели и аварии вымышлены; подключения к оборудованию и корпоративным системам нет. Официальные логотипы KAZ Minerals не используются.

## Публикация с iPhone — без компьютера и терминала

1. В Safari откройте [репозиторий](https://github.com/alikingod/ruslan1993). Если изменения переданы через Pull Request, откройте его → **Merge pull request → Confirm merge**.
2. В репозитории откройте **Settings → Pages** (вкладка Settings может находиться в меню `…`). Если мобильный интерфейс скрывает настройки, выберите в меню Safari «Запросить настольный веб-сайт».
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**. Для бесплатного GitHub Pages репозиторий должен быть публичным; для приватного может потребоваться тариф GitHub.
4. Откройте **Actions → Build and deploy Rusya 1993**. Запуск происходит автоматически после изменения `main`. Если он был красным до включения Pages, нажмите **Re-run all jobs** или **Run workflow → main → Run workflow**.
5. Дождитесь зелёной отметки у `deploy`. Ссылка появится в **Settings → Pages** и в окружении **github-pages**.
6. Откройте https://alikingod.github.io/ruslan1993/ и отправьте ссылку Руслану.

Если Actions сообщает `Resource not accessible by integration`, проверьте **Settings → Actions → General**, разрешены ли GitHub Actions. При ограничениях окружения `github-pages` разрешите публикацию из ветки `main` в **Settings → Environments**.

Следующие изменения в `main` публикуются автоматически. Секреты, ключи API и установка чего-либо на iPhone не нужны. В Safari можно выбрать **Поделиться → На экран «Домой»**. Приложение требует интернет для первоначальной загрузки; офлайн-режим не заявлен.

## Что внутри

- `/` — пропускаемая загрузка терминала; `/dashboard` — панель и учебная авария.
- `/dossier` — досье, документы, возраст и отсчёт; `/simulator` — игра с тремя сложностями.
- `/mentor` — имитация звонка и режим ярости; `/academy` — пять вопросов, результат, печать сертификата.
- `/achievements` — коллекция; `/final` — благодарность наставнику после трёх заданий.

Используется HashRouter: ссылки вида `/#/simulator` работают на GitHub Pages без настройки сервера. Vite `base: './'` поддерживает путь репозитория и переименование папки, без жёстко заданного домена.

## Прогресс, звук и дата

Прогресс сохраняется в localStorage текущего браузера под ключом `rusya1993-v1`. На разных устройствах он независим. Сброс — в достижениях или кнопкой внизу боковой панели; требуется подтверждение. При недоступном localStorage появится уведомление, приложение продолжит работу в памяти.

Звук выключен при каждом открытии. Включить/выключить — кнопкой динамика сверху. Звуки синтезируются через Web Audio, записей и реальных звонков нет. Анимации учитывают `prefers-reduced-motion`; мобильная навигация учитывает safe area. Портрет или реальные фото Руслана не выдумывались: вместо них использована графическая эмблема.

Возраст и праздник рассчитываются по локальной дате устройства. 28 декабря автоматически появляется золотой интерфейс и праздничное окно. Кнопка подарка сверху и кнопка в досье открывают предпросмотр в любой день. Предпросмотр показывает возраст на ближайший день рождения; текущий возраст указан отдельно. Дата проверяется каждые 30 секунд, поэтому режим включится даже в оставленной открытой вкладке.

## Подсказки и секреты (спойлеры)

1. Нажмите логотип слева пять раз. На телефоне альтернативный вход — служебный люк в досье.
2. Откройте служебный люк в досье: система узнает секретного сотрудника.
3. Удерживайте печать в досье две секунды (с клавиатуры — Enter).
4. В симуляторе нажмите **Сгустить → Добавить флокулянт → Позвать Русю**.
5. На странице связи позвоните пять раз с интервалом не более 15 секунд. Дождитесь ответа перед следующим звонком. Ярость пройдёт через пять секунд.
6. Откройте подарок и поздравьте легенду — достижение доступно и в предпросмотре.

Победа в симуляторе: сгущение ≥ 90%, стабильность ≥ 70%, хаос ≤ 20%. Возможный путь на всех сложностях: трижды флокулянт, затем четырежды Руся. Сложность «Легенда» даёт дополнительное достижение. Смена сложности начинает новую смену; полученные достижения сохраняются.

Финал открывается после **победы в симуляторе + прохождения академии + звонка наставнику**. Академия выдаёт сертификат за полное прохождение с любым результатом; число верных ответов показывается отдельно. Кнопка печати в Safari открывает системный диалог, из которого можно сохранить PDF через «Поделиться».

## Для разработки

Node.js 22+, `npm ci`, затем `npm run dev`. `npm test` проверяет даты, границы игровых шкал, достижимость победы и допуск к финалу. `npm run typecheck` проверяет TypeScript. `npm run build` выполняет проверку и production build в `dist/`.

Стек: React 19, TypeScript, Vite, Tailwind CSS 4, Motion, React Router, Lucide React, SVG. Графика и шрифты системные, внешних CDN, серверов и платных API нет.
